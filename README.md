# Rejected Olympic Sports Entry

## Overview
This project deterministically generates a competitive entry for the "Rejected Olympic Sports" make.fun bounty. The entry captures the deadpan drama of an Olympic sports broadcast applied to a mundane domestic hazard, culminating in an absurd twist.

The entry is written to `/output/entry.txt` (or a path specified via the `ENTRY_OUTPUT` environment variable).

## How to Run
Run the entry generator using:

```bash
python3 main.py
```
